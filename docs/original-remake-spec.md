# オリジナルの作り直し（original-remake-v1）

オリジナルの人の 2 体（ハル `generic-human-a`、ナミ `generic-human-b`）の髪・体（服）を Tripo で作り直し、肌の継ぎ目と、動作中のうつむきを直す。
目的は、通常の Studio の画面で「明らかに良くなった」と分かること。判定は ChatGPT と決めた合格条件（下）で行う。

## 誰が何をして、どうなればよいか

- Studio でハル・ナミを開くと、髪が自然な束で、服の形（上着・インナー・パンツ・靴）が読め、耳の前〜あご〜首に継ぎ目の線が無い。
- 「手を振る」などの動作で、顔が前を向く（下を向かない）。
- 今までの編集（頭・目・口の形、髪型、髪の色、体型、表情、16 動作、武器）と GLB の書き出しが、そのまま使える。

## 今回の範囲

| 対象 | 内容 | 状態 |
|---|---|---|
| ハル: 髪 6 種・体と服・肌・首 | 作り直し | 済み |
| ナミ: 髪 4 種（ボブ・ピクシー・ロングウェーブ・ハイポニー）・体と服・肌・首 | 作り直し | 済み |
| 4 体: 動作中のうつむき | `build-original-action-motions.mjs` の基準の姿で、頭をモデルの素の向きへ戻す | 済み |
| 一覧の顔写真・髪型と頭・目・口の選択のサムネイル | 新しい見た目で撮り直す（`shoot-original-thumbnails.mjs`） | 済み |

ナミのモデルに残っている `nagi-wavy-lob-v3`（画面の選択肢には無く、保存を読むと `nagi-long-v2` に読み替わる髪）は作り直していない。

やらないこと: ルクス・モカの形の作り直し（ChatGPT の判断: 出来が良いので姿勢だけ）。骨（41 本）・動作の名前・表情の名前・保存形式は変えない。

## 作り方

骨・動作・顔の部品（目・眉・まつ毛・口）・頭の形は今のモデルのまま使い、髪と体の「形と絵」だけを替える。

1. **原画**（ChatGPT の画像生成）: 正面・横（顔が左向き）・後ろの 3 枚。髪は今の頭の写真を見本に、体は今のモデルの基準の姿（A ポーズ）の描画を見本にして、同じ姿勢・同じ大きさで描く。
   髪でも体でも、**頭・顔・首は目鼻口の無い緑一色（#00C800）のマネキン**にする。あとで緑の面を消して、髪だけ・体だけを取り出すため。
2. **立体化**（Tripo Studio H3.1、複数視点: 前・左・背面、ウルトラメッシュ、4K、ライティング除去）。GLB（テクスチャ 2k）で書き出す。
3. **合わせる**（Blender、`tools/character-maker/remake/`）
   - `fit-hair.py`: 緑の面（マネキン）を今の頭・顔・首の面へ重ねて、大きさと位置を決める（回転はしない）。緑の面を消し、消した跡の縁を均し、頭皮に沿う土台（髪に隠れる頭の面を少し外へ出した物）を足す。
     髪の絵は作り直す: Tripo の絵は陰を消してあって束が読めず、色も原画からずれるので、決まった髪色（ハル `#302b30`、ナミ `#795142`）に、くぼみの陰（Blender で焼く AO）と元の絵の明暗を掛ける。
     Tripo の GLB は絵の継ぎ目で頂点が分かれているので、同じ位置の頂点を先につなぐ（つながないと、継ぎ目を縁と見て形が裂ける）。
   - `fit-body.py`: 体を今の体へ重ねる。緑の面を消し、手の肌色を顔の肌色へ寄せ、襟の内側と緑のにじみを上着の暗い色で塗る。
4. **差し替える**（node、`tools/character-maker/`）
   - `remake-original-hair.mjs`: 髪のノード（`OriginalModularHair_<髪型>`）の名前・目印（extras）はそのまま、形と材質を替える。骨は `Head` に 1.0。
   - `remake-original-skin.mjs`: 頭の肌の絵を、顔の中央の肌色へそろえてならす（島の縁のにじみと焼き込まれた陰が、継ぎ目の線に見えていた）。
   - `remake-original-body.mjs`: 体のノードの形と絵を替える。骨の重みは今の体の近い 4 頂点から写す。頭の部品のいちばん下の輪から、襟の内側へ下りる首の筒（`OriginalNeckBridge`）を足す（新しい服は襟が開いているので、首の下にすき間が見えないように）。
     武器を握る手の「元の手の三角形」を、新しい体の番号で書き出す（`parts/assets/original-remake-v1/<id>-hand.json`）。
5. **登録**: `node tools/character-maker/remake-original.mjs --id=<id>` が 3・4 を通しで行い、モデルを `parts/assets/studio-runtime-v1/models/<sha256>.glb` に置いて、
   `studio-runtime-v1/manifest.json` と `studio-catalog.json` の sha256 を書き換える。続けて `build-original-action-motions.mjs`・`build-original-hit-motions.mjs`・`pnpm assets:sync`。

素材の置き場所（`parts/assets/original-remake-v1/`）: `base/<id>.glb`（作り直す前のモデル）、`sources/<id>/`（Tripo の出力と原画）、`manifest.json`（入力と出力の sha256）。

## 合格条件（ChatGPT と 2026-11-16 に決めた物）

1. 通常の Studio 表示で差が出る（全身 400px・顔 300px で並べて分かる）。
2. 髪の形が自然に読める（頭皮の穴、帽子状の境界、同じ厚さの束の反復が無い。正面・斜め・横・背面）。
3. 顔の接合線が消える（耳の前〜あご〜首）。
4. 服の構造が読める。
5. 挨拶で相手を向く（待機と手振りで顔の正面が水平 ±5° 程度）。
6. 機能を維持する（髪 6＋5 種、各編集項目、全表情、16 動作、武器、GLB 出力）。

前後の比較は 7 組（顔: 正面・斜め・横・背面、全身: 正面待機・横待機・手を振る）。自動まばたきは止めて撮る。

## 後で仕上げること

- Tripo の入力を入れ替えるときは、ページを開き直してから入れる（前の画像が残った枠には入らない。2026-11-16 に 3 回分を無駄にした）。

- 服の絵は寄ると少しぼやける（2k）。配布の容量と合わせて決める。
- 配布用の tgz・配布用 Stage は、この作り直しを含めて更新していない。
