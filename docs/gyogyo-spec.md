# 魚々娘（ぎょぎょむすめ / GYOGYO MUSUME）

きゃしー・魚・イカが雲の上の競馬場を走る、ひとり用の3Dレースゲームです。[かけっこグランプリ](https://kakekko.yukikau.jp/) をもとに作りました。ビルド手順と操作方法は [ゲームの README](../games/gyogyo/README.md) にあります。

## だれが何をして、どうなるか

| だれが何をする | 結果 |
|---|---|
| `pnpm gyogyo:build` のあと `pnpm dev` で http://127.0.0.1:4284/gyogyo/index.html を開く | タイトル「魚々娘」が出る。裏で魚たちが走っている |
| 出走登録で走る人を選ぶ | きゃしー・Studio から送ったキャラ・魚 10 種・イカ 2 種から選べる。選ばなかった人から 7 人が CPU で走る |
| 魚を選んで走る | 魚が走路の上を、頭から尾へうねって泳いで進む。ダッシュは速く大きく尾を振る |
| イカを選んで走る | イカが外套の先を前にして、ひれを波打たせて進む。ダッシュはジェットで腕をそろえて進む |
| 武器を拾って攻撃する・当てられる・ゴールする | 遊び（マーク・武器・脚質・育成・3 戦カップ）はかけっこグランプリと同じ。魚とイカは攻撃・あいさつ・喜びで宙返りする |
| タイトルの「かけっこグランプリでみんなで走る ↗」を押す | かけっこグランプリ（https://kakekko.yukikau.jp/）が同じタブで開く（下の「みんなで」） |
| Studio（`/character-maker`）で「魚々娘で遊ぶ」のカードを押す | そのキャラを選んだ状態で魚々娘が開く（下の「Studio の入口」） |

## 走る人たち

| 走る人 | 出どころ | 体の作り（`rust/game/src/view/`） |
|---|---|---|
| きゃしー | 魚群繚乱と同じ 1 体の配布（`public/delivery/`。同じ場所から読む） | 人の形（characters の部品 character-actor） |
| つくったキャラ（Studio から送った 1 体） | ブラウザの控えの `.character.zip` | 人の形。背はきゃしーにそろえる |
| 魚 10 種（マダイ・ブリ・キハダ・サバ・アジ・カサゴ・タチウオ・マゴチ・クロダイ・シーバス） | Fish Kit（CC0） | `fish.rs`。全長 2.3〜3.9 m、腹が地面から 0.35 m 浮く。うねりは Fish Kit の式と、glb の `extras.swim` の値 |
| イカ 2 種（アオリイカ・コウイカ） | Squid Kit（CC0） | `squid.rs`（Squid Kit の three.js のコードを Rust へ移した） |

- 名簿の並び: きゃしー → つくったキャラ → 魚 → イカ。

魚、イカ、人型の走者に共通の移動速度・当たり判定・スタミナ計算を使います。選んだ魚やイカによってモデルと泳ぎ方が変わります。

## レースと育成

1レースは8人で競います。進路を選び、スタミナを配分してダッシュし、走路のマークやアイテムを使います。3戦のカップと、デビューから引退までの全8戦を走る育成モードがあります。難易度ごとにCPUの速度とプレイヤーのダッシュによるスタミナ消費を調整しています。計算とテストは [rust/sim](../games/gyogyo/rust/sim/) にあります。

## みんなで

タイトルの「かけっこグランプリでみんなで走る ↗」から、最大4人で走れる [かけっこグランプリ](https://kakekko.yukikau.jp/) を開けます。

## Studio の入口

| だれが何をする | 結果 |
|---|---|
| Studio を開く | ステージの左下に、魚群繚乱のカードと、その上に魚々娘のカード（タイトル画面を録った動画と「魚々娘で遊ぶ」）が積んで出る。顔の表示では 2 枚とも札 |
| 「魚々娘で遊ぶ」を押す | Studio がゲーム用の `.character.zip`（魚群繚乱と同じ形・同じ書き出し）を作り、控えに置いて `/gyogyo/index.html?from=studio` を開く |
| 魚々娘が始まる | 控えの ZIP を名簿の 2 番目（id `studio`）に入れ、`from=studio` ならそのキャラを選んだ状態にする |
| 魚々娘がまだ作られていない | 飛ばずに「`pnpm gyogyo:build` を実行してから」と知らせる |

作り:

| 項目 | 決まり |
|---|---|
| 渡し方 | `lib/character-maker/game-handoff.ts`（魚群繚乱と共通）。控えの名前 `character-maker-gyogyo-v1`、キー `/gyogyo/studio-character.zip`（`games/gyogyo/rust/web/index.html` と同じ値） |
| `from=studio` | `index.html` が読んで `window.__gyogyoFromStudio` に置き、URL からすぐ外す（Rust が名簿を作るのは字体・配布を読んだ後なので、URL のままだと先に消えていた） |
| カード | `components/character-maker/GameCard.tsx`（魚群繚乱と共通）。下から魚群繚乱・魚々娘の順に積む（`STUDIO_GAME_ORDER`）。上のカードは下のカードの高さ＋10px だけ上 |
| 動画 | `public/character-maker/gyogyo-title.mp4`（480×270・24 コマ/秒・4.4 秒・音なし・約 190KB。終わりの 0.6 秒を始めへ重ねてつなぎ目を消した）、止め絵 `gyogyo-title.jpg` |
| 名前の字 | 字体は使う字だけに絞ってある（かな・英数・記号・JIS 第一水準の漢字）。それ以外の字を名前に使うと出ない（魚群繚乱と同じ） |
| 保存 | 走る人・記録・設定は `gyogyo.save`・`gyogyo.keys`・`gyogyo.audio`（かけっこグランプリの保存とは別） |
