The three `.vrm` files are immutable originals copied from the public OpenGameArt downloads listed in `provenance.json`. Only the files needed for this maker are retained; archive ZIP files are not duplicated.

- Victoria Rubin: old beta AvatarSample_4 / mirror filename AvatarSample_G.vrm. Official individual license: https://vroid.pixiv.help/hc/ja/articles/360014900233
- Sakurada Fumiriya: normal version, not the separate child model. Official individual license: https://vroid.pixiv.help/hc/en-us/articles/360014788554-Sakurada-Fumiriya
- HairSample_Male: beta hair sample. Official beta sample license: https://vroid.pixiv.help/hc/ja/articles/4402614652569

The current AvatarSample A–Z collection has different terms and is not an input. The old Victoria/Sakurada files embed `licenseName: Other` and permissive Hub license links; their individual official articles establish CC0. HairSample_Male embeds `licenseName: CC0`. Full original metadata, logical IDs, original filenames, exact hashes and source URLs are in `provenance.json`.

Original hair skeletons, weights, VRM expressions and secondary spring settings remain in these originals even though the maker outputs static detachable hair. Three-vrm code is MIT; this does not substitute for the model's own CC0 license.
