# メインキャラ対応：のけぞり と ＞＜（2026-10-16）

ゲームのメインキャラとして使えるように、全キャラ（オリジナル4体・ファンタジー8体・アメコミ4体）に「食らったときのポーズ（のけぞり）」と「＞＜ の顔」を足す。

## 利用者が見ること

- Studio の「動き」に **のけぞる** ボタンを足す。押すと1回のけぞり、終わると元の動き（待機・歩く・走る・構える…）へ戻る。連打すると最初から再生し直す。
- のけぞっている間は、顔が自動で **＞＜** になる。
- 表情のところに **＞＜** の切り替えを足す。押している間は ＞＜ の顔のまま（のけぞらなくても見られる）。
- のけぞり・＞＜ はその場の再生操作で、保存データ（JSON）には入れない。保存形式は変えない。
- 旧画面（`/character-maker/classic`、aisns が埋め込む）は見た目と操作を変えない。書き出す GLB には下の内容が入る。

## GLB の契約（ゲームで使う人向け）

書き出す GLB（標準・武器あり、どちらも）に次を入れる。名前は `lib/character-maker/hurt.ts` の定数が正本。

| 名前 | 種類 | 中身 |
|---|---|---|
| `hit` | アニメーションクリップ | 体ののけぞり（UAL1 `Hit_Chest` を元に約0.66秒、最後は待機の姿に戻る）＋ ＞＜ の表示。一回再生（LoopOnce）を想定 |
| `face_hurt` | アニメーションクリップ | ＞＜ を出し続けるだけ（体の骨は動かさない）。ループ再生か、他のクリップと同時に重ねて使う |
| `maker-hurt-face` | ノード | ＞＜ の顔の部品。通常は scale 0。`hit` と `face_hurt` の scale トラックで 1 になる（visible ではなく scale で切り替える） |

- ＞＜ の出し方は系統で違う。ゲーム側は **`face_hurt` を他のクリップと重ねて再生する**（ノードの scale を手で変えるのではなく）。
  - オリジナル・アメコミ・ファンタジー男性: `maker-hurt-face` の板の scale を 1 にする。オリジナルは目を閉じるまばたきのモーフのトラックも入る（開いた目が板より手前に出ないように）。
  - ファンタジー女性: VRM の表情 `Extra`（＞＜ の絵）のモーフの重みで出す。`maker-hurt-face` は中身のない目印のノード。
  - GLB の extras の `export.reactions` に、この使い方を書いている。
- 武器ありの書き出しでは `hit` の間も武器を表示する。標準の書き出しでは武器を出さない（`weapon.ts` の規則）。
- 既存のクリップ（idle・walk・run・sword_idle・sword_attack）のバイト列は変えない。のけぞりのクリップは追加分だけ作って足す。

## 作り方（系統ごと）

| 系統 | のけぞり | ＞＜ |
|---|---|---|
| オリジナル4体（Tripo のリグ） | UAL1 `Hit_Chest` を各体の骨へ移す（剣の動作と同じ考え方） | characters の `createHurtFace`（まばたきで目を閉じ、頭の骨に ＞ の絵の板を重ねる）を移植 |
| ファンタジー（VRoid β） | UAL1 `Hit_Chest` を `build-extended-motions.mjs` と同じ方法で | 女性は VRM の表情 `Extra`（＞＜ の絵）。男性はモーフが無いので板を重ねる |
| アメコミ（Quaternius） | 同上 | 目のメッシュの形に合わせた板に ＞ の絵を貼る（左右の UV 反転で ＞＜ になる） |

## 確かめること

- 単体テストと既存の E2E がすべて通る。
- 各系統の代表キャラで、のけぞる→元の動きへ戻る、＞＜ が出て消える、を画面で確かめる。
- 書き出した GLB を読み直し、`hit`・`face_hurt`・`maker-hurt-face` があり、`hit` を再生すると ＞＜ が出ることを確かめる。
